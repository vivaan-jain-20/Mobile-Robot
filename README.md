# Mobile Robot - Term Project

Welcome to the repository for our differential drive mobile robot project. Below is a complete directory of the project files, including our mechanical designs, control code, and presentation materials.

## 📄 Project Documentation

* **[Term Project Presentation](Term%20Project.pdf):** The full slide deck outlining the mechanical chassis specifications, component list, and FSM diagrams. *(Click to view directly in your browser!)*
* **[Literature Review](Literature_review.docx):** Background research, methodology, and the theoretical foundation of the project.

## 🤖 Hardware & Circuit Design

* **[Circuit Schematic Diagram](Term%20Project%20Circuit.pdf):** A clean, readable PDF export of our Tinkercad circuit wiring and layout.
* **[SolidWorks Assembly](Design.SLDASM):** The 3D CAD model of the robot chassis and mounted components. *(Requires SolidWorks to open).*
* **[Circuit Board Design](Circuit.brd):** The PCB layout file for the control electronics.

## 💻 Software

* **[Arduino Code](Arduino_code.ino):** The C++ source code for the Arduino Uno, handling the motor driver logic, ultrasonic sensor scanning, and the state machine.

## 🎥 Media Demonstration

* **[Project Animation](Animation.mkv):** A video demonstration of the robot in action. 
*(Note: GitHub does not natively play .mkv files in the browser, so you may need to click the "Download" or "View Raw" button to watch it locally).*
